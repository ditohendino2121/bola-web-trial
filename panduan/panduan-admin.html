1. Pengenalan & Peran Admin

Web MUBA FC di https://muba-fc.vercel.app menggantikan list WhatsApp dan catatan manual. Datanya online dan sinkron antar HP. Tugas admin:

  • Menyetujui pendaftar baru agar orang luar tidak masuk sembarangan.
  • Membuat jadwal main dan mengatur statusnya.
  • Check-in pemain di lapangan dan mencatat pembayaran cash.
  • Memverifikasi klaim pembayaran dan mengelola kredit pemain.
  • Mencatat kas awal, pengeluaran, sponsor, dan mengunduh laporan keuangan.
  • Mengelola liga 6 bulan.
📌 Prinsip pentingSistem yang menagih, bukan admin yang sungkan menagih. Aturan H-2, tunggakan, dan blokir otomatis ditegakkan web — admin hanya menangani pengecualian.

2. Login Admin

  1. Buka https://muba-fc.vercel.app di HP.
  2. Beranda → Sudah punya akun → Masuk dengan email + password admin (dibuat via Supabase, bukan akun trial).
  3. Menu 🛠️ Admin di sidebar hanya berfungsi penuh untuk akun ber-peran admin.
  4. Setelah login pertama, segera ganti password berkala dan jangan dibagikan ke pemain.

3. Approve Pendaftar Baru

  1. Buka Admin → ✅ Approve pendaftar. Pendaftar baru berstatus pending dan tidak bisa isi list sebelum di-approve.
  2. Cek nama, WA, dan email. Kenali orangnya? Klik Approve ✅. Tidak kenal? Tolak.
⚠️ KeamananJangan approve yang tidak dikenal. Satu orang satu akun.

4. Kelola Jadwal Main

Buka Admin → 📅 Kelola Jadwal.

Membuat jadwal

  1. Isi Tanggal, Jam (contoh 20:00-22:00), Lokasi → Buat Jadwal.
  2. Kuota otomatis 28 orang (GK 4 • Belakang/Tengah/Depan @8). Jadwal langsung muncul di HP pemain.

Mengubah & menghapus

  • ✏️ Ubah: ganti tanggal/jam/lokasi. Peserta yang sudah list tidak hilang.
  • 🗑️ Hapus: jika sudah ada yang ikut, sistem minta konfirmasi dan mengembalikan kredit deposit otomatis (ke bucket asal: GK kembali ke GK).

5. Roster per Tanggal & Check-in Lapangan

Halaman utama kerja lapangan: Admin → 👥 Roster per tanggal → pilih tanggal game. Peserta dikelompokkan per posisi + badge: ✅ Lunas • 💵 Di tempat • 🔒 Wajib bayar. Tombol 📋 Salin ke WA menyalin list rapi per posisi untuk ditempel ke grup.

Void tunggakan

Kasus darurat (sakit, duka) atau bantuan: klik Void + isi alasan (hanya terlihat admin). Pemain bisa isi list lagi.

6. Walk-in: Datang Tanpa Isi List

  1. Di Roster, buka kartu 🚶 Walk-in H-day.
  2. Pilih pemain (yang sudah di list tidak muncul), posisi, dan cara: Potong 1 kredit (GK pakai kredit GK dulu) atau Lunas cash (otomatis 15rb jika GK, 25rb lainnya).
  3. Tambah ke List. Kuota dan slot posisi dicek otomatis.

7. Verifikasi Pembayaran (QRIS/Transfer)

  1. Pemain bayar ke QRIS/rekening komunitas lalu kirim konfirmasi dari menu Top-Up (boleh harga Pemain atau harga GK 🧤).
  2. Admin → 💳 Verifikasi pembayaran: cek nama, paket, metode, info bukti vs mutasi.
  3. Cocok? Setujui ✅ → kredit masuk ke bucket yang sesuai (klaim GK masuk kredit GK). Paket 4x (90rb maupun 50rb GK) otomatis menjadikan pemain ⭐ Member. Tidak cocok? Tolak + alasan (terlihat pemain).

8. Kredit Manual: Cash, Bantuan & Koreksi

Kartu ➕ Kredit manual memakai model pilih-nama-dulu: ketik/cari di kolom 🔍 (atau buka dropdown), pilih 1 pemain → kartu aksi muncul (saldo + semua tombol). Pilihan bertahan setelah aksi, enak untuk input beruntun.

  • +1 / +4 cash — bayar tunai tanpa klaim (25rb/90rb).
  • +1 / +4 GK — harga kiper (15rb/50rb), masuk bucket GK.
  • −1 R / −1 P / −1 RGK — kurangi kredit (wajib isi alasan, tercatat privat).
  • Jadi/Cabut ⭐ — atur member manual.
  • 🎗️ Kredit bantuan (privat) — untuk pemain yang tidak mampu bayar. Pemain hanya melihat label netral “Kredit admin”; alasan hanya terlihat admin dan tidak dihitung pemasukan kas.

9. Hapus Data Salah Input

  • Kas → Hapus per baris: kredit yang terlanjur masuk ditarik kembali otomatis (ke bucket yang benar, tidak sampai minus). Ada konfirmasi yang menjelaskan efeknya.
  • Pengeluaran & sponsor: tombol Ubah/Hapus di halaman Keuangan.
  • Jadwal: hapus jadwal mengembalikan kredit deposit otomatis.
  • Membatalkan RSVP pemain: hanya via Tarik List (sebelum H-2) atau Void tunggakan.

10. Member, Harga GK & Aturan Sistem

PemainKiper (GK) 🧤
Sekali mainRp25rb = 1 kreditRp15rb = 1 kredit GK
Paket 4x (member ⭐)Rp90rb = 4 kreditRp50rb = 4 kredit GK
  • Member permanen = pernah beli paket 4x (90rb/50rb GK) yang disetujui. Kredit habis tidak menghilangkan member. Liga khusus member.
  • Kredit GK terkunci: hanya bisa dipakai saat main sebagai GK. Main posisi lain memakai kredit normal. Refund kembali ke bucket asal.
  • Cara ikut tinggal 2: potong deposit atau bayar cash di tempat (opsi utang sudah dihapus).
📌 Aturan H-2Batal/refund hanya sampai H-2. Setelah itu tetap wajib bayar (25rb / GK 15rb) walau tidak datang. Belum bayar = tidak bisa isi list game berikutnya — termasuk bayar-di-tempat yang belum dikonfirmasi lunas.

11. Keuangan: Kas Awal, Pengeluaran, Sponsor

Buka Admin → 💰 Keuangan & PL, pilih periode bulan.

  • 🏦 Kas awal: uang kas sebelum web dipakai. Input sekali (nominal + tanggal) → otomatis jadi saldo pembuka tiap bulan.
  • Pengeluaran: Tanggal → Jenis (Sewa Lapangan / Makanan dan Minuman / Transportasi / Bank Fee) → Keterangan → Nominal. Bisa ubah/hapus.
  • 🤝 Sponsor/manual: Tanggal → Sumber → Keterangan → Nominal. Pemasukan pemain otomatis dari kas; form ini khusus sponsor & luar kas.

12. Laporan Laba Rugi & Arus Kas (PDF)

  • Saldo awal → A. Pemasukan (A1 kas otomatis + A2 sponsor) → B. Pengeluaran → Surplus/Defisit → Saldo akhir.
  • C. Arus Kas: saldo awal → arus masuk (iuran vs sponsor) → arus keluar per jenis → kas bersih → saldo akhir.
  • ⬇️ Download PDF: Cetak → Save as PDF. Hasil: kop MUBA FC + logo + basecamp + tabel + tanda tangan. ⬇️ CSV untuk Excel.
✅ TransparansiDeposit adalah titipan main, bukan laba bersih. Laporan ini adalah arus kas komunitas — footnote tercantum di dokumen.

13. Kelola Liga 6 Bulan

  1. Member daftar ke Tim A/B/C/D + posisi (per tim 7 orang: GK 1, Belakang/Tengah/Depan @2). Non-member ditolak otomatis.
  2. 🔒 Kunci Skuad saat final — tidak bisa daftar/pindah 6 bulan. Pergantian via Keluarkan per pemain.
  3. Buat jadwal tanding kapan saja (Home vs Away + tanggal + jam + lokasi). Bisa hapus.
  4. Input skor + pencetak gol (pisah koma) → klasemen (M3/S1/K0) & top skor otomatis.

14. Export Data & Acak Tim

  • Database pemain: ⬇️ CSV (nama, WA, email, status, member, kredit P/R/GK, tunggakan Rp, total ikut) + 🖨️ Cetak/PDF.
  • Per jadwal: di Roster → CSV / Cetak. 🎲 Acak 4 Tim (seimbang posisi, bisa acak ulang) → CSV + kolom Tim.
