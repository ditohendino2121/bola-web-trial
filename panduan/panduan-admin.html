1. Peran Admin

Mengelola pendaftaran, jadwal, pembayaran, roster H-day, keuangan, dan liga. Semua tindakan tercatat di Kas.

2. Login & Keamanan

  1. Buka https://muba-fc.vercel.app → Beranda → Masuk (email+password admin).
  2. Menu 🛠️ Admin hanya untuk role admin. Ganti password berkala via Supabase → Users → Reset.
  3. 2 admin aktif. Menambah admin: SQL update profiles role.

3. Approve Pendaftar

Admin → Approve: pending tidak bisa isi list. Cek nama/WA → Approve ✅ / Tolak.

4. Kelola Jadwal FUN

Admin → Kelola Jadwal: Tanggal/Jam/Lokasi → kuota 28 (GK4/Belakang8/Tengah8/Depan8). Status: buka/tutup/full_booked/sparing-14. Hapus mengembalikan kredit deposit (GK ke GK).

5. Roster, Check-in & Radar Tunggakan

  • Roster per tanggal: pilih jadwal → daftar per posisi + badge ✅ Lunas / 💵 Di tempat / 🔒 Wajib bayar.
  • Check-in: Lunas ✅ / Belum bayar → tunggakan / Tidak datang → no-show atau hutang.
  • Radar: ringkasan “Belum bayar: x orang • Rp...” + filter Semua/Belum/Lunas + checkbox bulk + Lunaskan terpilih (1 klik). Void untuk pengecualian.
  • Salin ke WA memakai template MUBA resmi, export CSV, acak tim.

6. Walk-in & Alih Slot

Walk-in: Roster → pilih pemain approved yang belum di list + posisi + potong/cash. Alih Slot (khusus admin): pilih slot (lunas/di tempat, bukan alihan) + pengganti approved yang belum di list → alihkan (deposit hangus privat, jejak alih_slot di Kas, maks 1x).

7. Verifikasi Pembayaran

Top-Up klaim (Pemain 25rb/90rb, GK 15rb/50rb) → Admin → Verifikasi: Setujui → kredit masuk bucket sesuai (GK ke GK), paket 4x jadi member. Tolak → alasan terlihat pemain.

8. Kredit Manual & Bantuan

Kartu Kredit manual: ketik/cari nama (combobox) → 1 pemain terpilih → +1/+4 cash, +1/+4 GK, −1 P/R/PGK/RGK, Jadi/Cabut ⭐. Bantuan privat: kredit masuk, pemain lihat “Kredit admin” netral, alasan hanya admin. Semua tercatat private_note.

9. Hapus & Koreksi

Kas → Hapus menarik kembali kredit (ke bucket benar). Pengeluaran/sponsor: Ubah/Hapus di Keuangan. Jadwal: hapus refund. RSVP: Void.

10. Keuangan & Laporan

Keuangan → Kas awal (sekali) → pengeluaran 4 jenis + sponsor manual → PL per bulan (Saldo awal = kas awal + carry-forward, A1 kas otomatis, A2 sponsor, B pengeluaran, Surplus, Saldo akhir) + Arus Kas. Download PDF kop MUBA + CSV.
