1. Pengenalan & Peran Admin

Web MUBA FC menggantikan list WhatsApp dan catatan manual. Tugas admin:

  • Menyetujui (approve) pendaftar baru agar orang luar tidak bisa masuk sembarangan.
  • Membuat jadwal main dan mengatur statusnya (buka / tutup / full booked / sparing).
  • Check-in pemain di lapangan dan mencatat pembayaran cash.
  • Memverifikasi klaim pembayaran (QRIS/transfer) dan mengelola kredit pemain.
  • Mencatat pengeluaran, sponsor, dan mengunduh laporan keuangan (PL + arus kas).
  • Mengelola liga 6 bulan (skuad, jadwal tanding, skor).
📌 Prinsip pentingSistem yang menagih, bukan admin yang sungkan menagih. Aturan H-2, tunggakan, dan blokir otomatis ditegakkan web — admin hanya menangani pengecualian.

2. Login sebagai Admin

  1. Buka alamat web (misal http://localhost:3000 di trial, atau alamat Vercel saat sudah online).
  2. Di Beranda pilih Sudah punya akun → Masuk.
  3. Nama: Admin, Password: admin123 (ganti password ini saat produksi!).
  4. Menu 🛠️ Admin di sidebar hanya terlihat fungsinya untuk akun admin.

3. Approve Pendaftar Baru

  1. Buka Admin → ✅ Approve pendaftar. Semua pendaftar baru berstatus pending dan tidak bisa isi list sebelum di-approve.
  2. Cek nama dan nomor WA. Kenali orangnya? Klik Approve ✅. Tidak kenal? Klik Tolak.
  3. Pemain yang di-approve otomatis bisa login dan isi list.
⚠️ KeamananJangan approve nomor yang tidak dikenal. Satu nomor WA hanya untuk satu akun.

4. Kelola Jadwal Main

Buka Admin → 📅 Kelola Jadwal.

Membuat jadwal

  1. Isi Tanggal (kalender), Jam (contoh 20:00-22:00), Lokasi.
  2. Klik Buat Jadwal. Kuota otomatis 28 orang (GK 4 • Belakang/Tengah/Depan @8).
  3. Jadwal langsung muncul di halaman Jadwal pemain.

Mengubah & menghapus

  • ✏️ Ubah: ganti tanggal/jam/lokasi. Peserta yang sudah list tidak hilang.
  • 🗑️ Hapus: jika sudah ada yang ikut, sistem meminta konfirmasi dan mengembalikan kredit yang sudah dipotong otomatis.

5. Roster per Tanggal (Check-in Lapangan)

Ini halaman utama kerja lapangan. Buka Admin → 👥 Roster per tanggal, pilih tanggal game.

  • Daftar peserta dikelompokkan per posisi + badge bayar: ✅ Lunas • 💵 Di tempat • 🔒 Wajib bayar.
  • 📋 Salin ke WA: 1 klik menyalin list rapi per posisi, tinggal paste ke grup.

Void tunggakan (pengecualian)

Untuk kasus darurat (sakit, duka) atau bantuan privat: klik Void pada tunggakan + isi alasan. Alasan hanya terlihat admin. Pemain kembali bisa isi list.

6. Walk-in: Pemain Datang Tanpa Isi List

  1. Di Roster per tanggal, buka kartu 🚶 Walk-in H-day.
  2. Pilih pemain (yang sudah di list tidak muncul), posisi, dan cara: Potong 1 kredit atau Lunas cash 25rb.
  3. Klik Tambah ke List. Kuota dan slot posisi dicek otomatis.

7. Pembayaran: Verifikasi, Cash & Bantuan

Verifikasi klaim (QRIS/transfer)

  1. Pemain bayar ke QRIS/rekening komunitas lalu kirim konfirmasi dari menu Top-Up.
  2. Di Admin → 💳 Verifikasi pembayaran muncul antrian: nama, paket, metode, info bukti.
  3. Cek mutasi/rekening. Cocok? Setujui ✅ → kredit masuk (paket 4x otomatis menjadikan pemain ⭐ Member). Tidak cocok? Tolak + isi alasan (terlihat pemain).

Top-up cash tanpa klaim

Di kartu ➕ Kredit manual: tiap pemain ada tombol +1 cash dan +4 cash. Untuk yang bayar tunai di lapangan tanpa sempat klaim. Tercatat di kas sebagai manual_cash.

Kredit bantuan (privat) 🎗️

🔒 Rahasia adminUntuk pemain yang tidak mampu bayar (hanya admin yang tahu). Pemain hanya melihat label netral “Kredit admin” — tanpa kata gratis/bantuan. Alasan asli hanya terlihat di panel admin dan tidak dihitung sebagai pemasukan kas.

8. Kurangi Kredit & Hapus Data Salah Input

  • −1 R / −1 P: kurangi 1 kredit reguler/paket pemain (wajib isi alasan, tercatat privat). Untuk koreksi atau walk-in khusus.
  • Hapus transaksi kas (📒 Kas terakhir → Hapus): untuk salah input top-up/pelunasan. Kredit yang terlanjur masuk otomatis ditarik kembali (tidak sampai minus). Konfirmasi menjelaskan efeknya sebelum dihapus.
  • Pengeluaran & sponsor: tombol Ubah/Hapus ada di halaman Keuangan.
  • Jadwal: hapus jadwal mengembalikan kredit deposit otomatis (lihat Bab 4).

10. Aturan Sistem: H-2, Tunggakan & Blokir

📌 Satu kalimat aturan“Bisa batal & refund hanya sampai H-2 (2 hari sebelum jam kickoff). Setelah itu slot sudah dihitung — tetap wajib bayar walau tidak datang. Belum bayar = tidak bisa ikut game berikutnya.”
Kapan tarik listPotong depositBayar di tempat
≥ H-2✅ Kredit kembali✅ List dibatalkan, tidak ditagih
< H-2 / tidak datang❌ Hangus❌ Tetap ditagih 25rb → kunci list berikutnya

Tombol “Tarik List” mati otomatis setelah H-2. Pengecualian darurat hanya via admin (batal paksa/void + alasan).

11. Keuangan: Kas Awal, Pengeluaran, Sponsor

Buka Admin → 💰 Keuangan & PL. Pilih periode bulan di atas.

Kas awal 🏦

Uang kas yang sudah ada sebelum web dipakai (misal sisa buku tulis). Input sekali: nominal + per tanggal. Otomatis menjadi saldo pembuka tiap bulan (carry-forward dari bulan-bulan sebelumnya).

Pengeluaran

Form: Tanggal → Jenis (Sewa Lapangan / Makanan dan Minuman / Transportasi / Bank Fee) → Keterangan → Nominal. Bisa ubah/hapus.

Pemasukan sponsor 🤝

Form: Tanggal → Sumber (cth “Sponsor Toko Berkah Jaya”) → Keterangan → Nominal. Pemasukan dari pemain (top-up/pelunasan) otomatis dari kas — form ini khusus sponsor & pemasukan luar kas.

12. Laporan Laba Rugi & Arus Kas (PDF)

Laporan per bulan tersusun otomatis:

  • Saldo awal bulan (kas awal + akumulasi bulan lalu).
  • A. Pemasukan: A1 otomatis kas + A2 sponsor/manual.
  • B. Pengeluaran per 4 jenis → Surplus/Defisit → Saldo akhir (kas di tangan).
  • C. Arus Kas: saldo awal → arus masuk (iuran vs sponsor) → arus keluar per jenis → kenaikan/penurunan bersih → saldo akhir.
  1. Klik ⬇️ Download PDF → dialog cetak → tujuan Save as PDF → Simpan. Hasil: kop MUBA FC + logo + alamat basecamp + tabel + tanda tangan admin.
  2. ⬇️ Export Excel (CSV) untuk olah lanjut di Excel.
✅ Catatan transparansiDeposit paket adalah titipan main pemain, bukan laba bersih. Laporan ini adalah arus kas komunitas — footnote ini tercantum di dokumen agar transparan ke anggota.

13. Kelola Liga 6 Bulan

  1. Member daftar ke Tim A/B/C/D + posisi (kuota per tim: GK 1, Belakang/Tengah/Depan @2). Non-member otomatis ditolak.
  2. Saat skuad final, klik 🔒 Kunci Skuad 6 Bulan — pemain tidak bisa daftar/pindah. Pergantian (cedera) dilakukan admin via tombol Keluarkan per pemain.
  3. Buat jadwal tanding kapan saja: pilih Home vs Away + tanggal + jam + lokasi → Tambah Pertandingan. Bisa hapus.
  4. Input skor + pencetak gol (pisah koma, cth Budi, Budi, Andi) → klasemen (M3/S1/K0) & top skor update otomatis.

14. Export Data & Acak Tim

  • Database pemain: Admin → ⬇️ Export Excel (CSV): nama, WA, status, member, kredit, tunggakan, total ikut. 🖨️ Cetak/PDF juga tersedia.
  • Per jadwal: di Roster → ⬇️ CSV Jadwal / Cetak. Untuk bagi tim: 🎲 Acak 4 Tim (seimbang per posisi, bisa acak ulang) → ⬇️ CSV + kolom Tim.
