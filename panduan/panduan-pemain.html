1. Selamat Datang & Harga

MUBA FC main rutin tiap pekan + Liga KIM x DnA (6 hari, 4 tim). Web https://muba-fc.vercel.app untuk daftar, bayar, dan lihat klasemen.

2. Daftar Akun & Akad

  1. Buka Beranda → Daftar baru → isi Nama, WA, Email, Password (min 6).
  2. Centang 6 akad (5 pernyataan + 1 final) — tombol Daftar terkunci sampai semua dicentang.
  3. Status pending → tunggu admin approve. Cek menu Akad untuk baca ulang. Versi: v1-sep2026.
  4. Login → Sudah punya akun → Masuk (email + password). Akun lama yang belum setuju akan diminta setuju sekali saat login.

4. Top-Up & Pembayaran

  1. Buka Top-Up → pilih Pemain / Kiper → pilih paket 1x/4x → pilih QRIS / Transfer / Cash.
  2. Bayar nominal pas → isi info bukti → Kirim Konfirmasi ke Admin → status ⏳ Dicek.
  3. Kredit masuk setelah Setujui (paket 4x otomatis jadi member). Jika Ditolak, baca alasan di Riwayatku.
💡 TipsGunakan kredit GK hanya untuk daftar sebagai GK — sistem menolak pemakaian silang.

5. Jadwal FUN Mingguan (28 pemain)

Buka Jadwal Main (28 slot: GK 4, Belakang/Tengah/Depan 8). Pilih posisi → ✅ Potong Kredit atau 💵 Cash di Tempat. Tidak ada utang di depan. Kuota penuh / posisi penuh ditolak. H-2, tunggakan, dan alih slot via admin berlaku seperti di bawah.

6. Registrasi KIM x DnA Health League

Khusus member. Buka Registrasi KIM x DnA Health League:

  • Pilih posisi → Gabung Pool (GK4/Belakang8/Tengah8/Depan8, pool penuh = terkunci).
  • Tunggu admin Kocok Jadi 4 Tim (tiap tim GK1/Belakang2/Tengah2/Depan2, adil, tidak mungkin 2 GK 1 tim). Sebelum lock boleh kocok ulang.
  • Setelah lock, skuad final 6 bulan — hanya admin bisa Keluarkan/tambah manual.
  • Tim: Panadol Medika FC, Mubacetamol FC, Ibuprofen FC, DnA Amoxilin FC.

7. Bayar Edisi Liga (1 edisi = 1 kredit)

Di Registrasi, setelah daftar pool/tim, scroll ke Edisi Liga — Jadwal & Pembayaran (1 edisi = 1 kredit):

  1. Pilih edisi (daftar semua edisi ke bawah, maks 6) → klik 1 edisi: 2 tombol ✅ Potong 1 Kredit (edisi) / 💵 Cash 25rb (GK 15rb). Posisi terkunci posisi skuadmu.
  2. Belum bayar sampai finalisasi dianggap ikut → admin finalisasi: potong/hutang atau Keluarkan.
  3. Batal sebelum H-2: kredit kembali. Lewat H-2: wajib bayar.
  4. Pengganti per edisi, bukan per laga — hubungi admin, admin yang alihkan.
